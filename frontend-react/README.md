# EnBW MetroCity Power - React Frontend Portal

Modern React 18 + Vite + Tailwind CSS frontend application for **Use Case 25: Smart Grid Solar Microgenerator Connection Approval (Inspired by EnBW)**.

Complies strictly with the **PROJECT DEVELOPMENT AND SUBMISSION GUIDELINES** (Milestone 2 Full-Stack Integration).

---

## 🎯 Alignment with Problem Statement & Guidelines

| Guideline Requirement | Frontend Component | Implementation Details |
|---|---|---|
| **Initiating & Managing Workflows** | `ApplicationWizard.jsx`, `ApplicationList.jsx` | Submits complete JSON payload with UUID `submissionId` via `POST /api/applications`, starts main BPMN process in Camunda 8. |
| **Dynamic Array Item Builder** | `DeviceArrayBuilder.jsx` | Supports dynamic addition/removal of inverters and battery units with serial numbers, models, and compliance certs to feed Camunda's **Multi-Instance parallel safety inspection**. |
| **Live Process Status Tracker** | `LiveProcessTracker.jsx`, `ProcessFlowChart.jsx`, `VariablesViewer.jsx` | Polls `GET /api/applications/{id}` to display active/finished BPMN element instances, open incidents, process variables, and child Call Activities. |
| **Custom Tasklist Inbox** | `TasklistInbox.jsx`, `FixRequestModal.jsx`, `CostOfferModal.jsx`, `DefectFixedModal.jsx`, `ContractSignModal.jsx` | Renders user tasks generated by workers (`FIX_REQUEST`, `COST_OFFER`, `DEFECT_FIX`, `CONTRACT_SIGN`), submitting responses to Spring Boot REST endpoints. |
| **Grid Operations & Emergencies** | `OpsConsole.jsx` | Broadcasts `grid-emergency` / `grid-emergency-lifted` signals to trigger the Event Sub-Process in Camunda, tracks active incidents, and controls fault injection. |

## 🚀 Getting Started

### Local Development
```bash
# Navigate to the frontend directory
cd frontend-react

# Install dependencies (Node 20+)
npm install

# Start the Vite development server (proxies to Spring Boot on :8090)
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173).

### Production Build & Containerization
```bash
# Build production bundle
npm run build

# Or build via Docker
docker build -t metrocity-frontend:latest .
docker run -p 80:80 metrocity-frontend:latest
```
